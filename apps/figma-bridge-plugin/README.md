# Pitch Monumentum Bridge — Figma plugin

This local development plugin imports a `pitch-figma-bridge` JSON payload generated by Pitch Monumentum.

## What it preserves

- one Figma frame per Pitch slide;
- stable `pitchId` in Figma plugin data;
- editable text nodes;
- editable rectangles/ellipses/triangles/custom vector path where supported;
- editable lines;
- image bytes as Figma image fills;
- editable frame/group containers;
- Pitch token bindings and component/master metadata as plugin data;
- original structured payload on every imported node.

Charts, tables and diagrams currently become editable fallback frames with their structured Pitch payload attached. A later importer pass can expand them into richer native Figma primitives without changing the bridge schema.

## Local use

1. Generate/download a Figma bridge JSON from Pitch Monumentum Delivery Center.
2. In Figma Desktop, import this folder's `manifest.json` as a development plugin.
3. Run **Pitch Monumentum Bridge**.
4. Paste the bridge JSON or choose the file.
5. Click **Import into Figma**.

Imported nodes retain Pitch IDs, which is the basis for later update/re-export rather than one-way anonymous paste.

## Fidelity rule

The bridge is not an SVG flattening path. Unsupported parity must remain explicit in bridge warnings or structured plugin data rather than being silently rasterized.
